# YouTube Downloader for Windows

[Download the latest installer](https://github.com/Dkillington/YouTubeDownloader-Releases/releases/latest)

Download and run **Dkillington.YouTubeDownloader-win-Setup.exe**. The installer includes the .NET runtime, yt-dlp, FFmpeg, and FFprobe.

## Updates

Open **Options → Updates** to check for updates or change automatic downloads. Installed copies check at startup and every six hours. Updates download in the background and apply the next time you open the app, without interrupting media downloads. Settings are preserved.

Existing standalone copies need to install this Setup once to enable automatic updates. A portable ZIP is also provided for manual use.

This repository contains release binaries and update feeds. Source is maintained separately.

## Included tools

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [FFmpeg](https://ffmpeg.org/), distributed by [BtbN FFmpeg Builds](https://github.com/BtbN/FFmpeg-Builds)

See each upstream project for its source and license terms.
